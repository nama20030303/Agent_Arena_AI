# Вселенная Знаний — AI Knowledge RPG

> **Образование — не функция игры. Образование — и есть игра.**

Мобильно-ориентированная образовательная RPG: пользователь исследует «вселенную знаний»,
осваивает концепты, общается с ИИ-Учителем, зарабатывает XP, открывает сундуки и
прокачивает профиль. Прогресс — только за реальное продемонстрированное знание.

## Что внутри

| Слой | Технологии | Описание |
|---|---|---|
| `backend/` | Python, FastAPI, SQLAlchemy, SQLite | API академии + **игровой слой** (`app/game/`): миры знаний, граф концептов, XP/уровни/ранги, ежедневные задания, сундуки, инвентарь, достижения, аудит событий, ИИ-Учитель |
| `frontend/` | React, TypeScript, Vite | Веб-приложение на русском: онбординг, Главная, Карта знаний, экран концепта с практикой, Учитель, Профиль, церемония открытия сундука |

### Игровой слой (`backend/app/game/`)

- **3 мира знаний**: Программирование (Python), Физика (механика), Математика — 27 узлов,
  81 задание, боссы в конце каждого мира, пререквизитный граф.
- **Сервер — единственный источник правды** (§74 спецификации): XP, уровни, сундуки,
  предметы и достижения генерируются только на сервере; каждое начисление пишется в
  `game_events` (§73).
- **Честная экономика**: никакого XP за повторное решение, прогресс только за знания,
  подсказки слегка снижают награду, но не наказывают.
- **Стрики с защитой**: пропущенный день можно закрыть «щитом серии».
- **ИИ-Учитель**: провайдер-независимый шлюз (`app/ai`). Без ключей работает
  детерминированный автономный режим на основе теории узлов — продукт полноценен офлайн.

## Запуск

```bash
# Backend (порт 8000)
cd backend
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000

# Frontend (порт 5173, проксирует /api на 8000)
cd frontend
npm install
npm run dev
```

ИИ-провайдер подключается через `.env` (`AI_PROVIDER`, `OPENAI_*` / `YANDEX_*` переменные —
см. `backend/app/config.py`). Без ключей всё работает в автономном режиме.

## Тесты

```bash
cd backend && .venv/bin/python -m pytest          # вся платформа
cd backend && .venv/bin/python -m pytest tests/test_game.py   # игровой слой
```
